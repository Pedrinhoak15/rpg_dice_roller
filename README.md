# RPG Dice Roller

Aplicativo Flutter de rolagem de dados para RPG.

O aplicativo permite escolher diferentes tipos de dados, realizar rolagens, adicionar modificadores e consultar o histórico salvo localmente.

## Integrantes

- Pedro Silva — desenvolvimento do aplicativo
- Nome do segundo integrante — interface e design
- Nome do terceiro integrante — testes e documentação

## Funcionalidades

- Rolagem de dados d4, d6, d8, d10, d12, d20 e d100
- Escolha da quantidade de dados
- Adição de modificadores positivos e negativos
- Exibição dos resultados individuais
- Exibição do resultado total
- Histórico local das rolagens
- Tema escuro com tons de vermelho e azul
- Aplicativo desenvolvido com Flutter e Dart

## Tecnologias utilizadas

- Flutter
- Dart
- SQLite
- VS Code
- Git e GitHub
